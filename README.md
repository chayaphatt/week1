## About This Assignment

งานชิ้นนี้เป็นการบ้านสัปดาห์ที่ 1 เป็นแบบฝึกหัดเริ่มต้นฝึกเขียนโค้ดทำหน้าเว็บ Resume / Portfolio แบบง่ายๆเพื่อเรียนรู้โครงสร้างพื้นฐานของ HTML:
* การใช้แท็กหัวข้อและจัดย่อหน้า (`<h1>`, `<h2>`, `<h3>`, `<p>`)
* การแทรกรูปภาพประกอบลงบนหน้าเว็บ (`<img>`)
* การจัดแบ่งส่วนเนื้อหาด้วย Semantic Tags (`<section>`, `<div>`)
* การสร้างไฮเปอร์ลิงก์เชื่อมต่อไปยังโปรไฟล์ภายนอก (`<a>`) เช่น Facebook ส่วนตัว
